================================================================================
  คู่มือการใช้งานระบบแปลภาษามือไทยด้วย AI/ML (Sign Language Translation)
================================================================================

โปรเจกต์นี้ใช้ MediaPipe Hands และ Pose สกัดจุดพิกัดร่างกาย 112 มิติ 
และปรับความยาวการเคลื่อนไหวเป็น 24 เฟรมคงที่ เพื่อจำแนกท่วงท่าภาษามือแบบเรียลไทม์

--------------------------------------------------------------------------------
0. การเตรียมพร้อมและสภาพแวดล้อม (Environment)
--------------------------------------------------------------------------------
เปิด Terminal (PowerShell หรือ CMD) ที่โฟลเดอร์โปรเจกต์นี้

สามารถเปิดใช้งานหน้าต่างโปรแกรม Desktop GUI หลักได้ทันทีด้วย:
  python main.py
(หรือ .\.venv\Scripts\python.exe main.py)

(หากยังไม่มีไฟล์โมเดล MediaPipe ให้รันคำสั่งดาวน์โหลดครั้งแรก):
  python src/download_models.py


--------------------------------------------------------------------------------
1. ทดสอบกล้องและมุมมอง (Camera Setup & Position Check)
--------------------------------------------------------------------------------
ก่อนเริ่มเก็บข้อมูล แนะนำให้ทดสอบมุมกล้องและแสงสว่างก่อน:
  
  คำสั่ง:
  python src/check_camera.py

  คำแนะนำการจัดตำแหน่งกล้อง (สำคัญมากสำหรับท่าที่มือประกบกัน เช่น สวัสดี/ไหว้):
  - ตำแหน่งกล้อง: แนะนำตั้งสูงระดับหน้าผาก หรือเหนือศีรษะ 15 - 20 ซม. แล้วก้มหน้ากล้องลงมา 20° - 30°
    (มุมนี้จะมองเห็นหลังมือทั้งสองข้างชัดเจน ไม่แบนเป็นเส้นเดียวเหมือนตั้งตรงระดับอก)
  - ระยะนั่ง: นั่งห่างจากกล้องประมาณ 70 - 90 ซม. (เห็นศีรษะถึงเอว)
  - แถบ Shoulder width ควรขึ้นข้อความ "distance OK" (สีเขียว)
  - ไหล่และข้อศอกทั้งสองข้างควรอยู่ในเฟรมกล้อง
  
  ปุ่มควบคุมในหน้าต่างทดสอบ:
  - [Q] หรือ [ESC] : ปิดโปรแกรม
  - [R]            : รีเซ็ตสถิติการตรวจจับ
  - [S]            : บันทึกภาพหน้าจอตัวอย่างลงโฟลเดอร์ results/


--------------------------------------------------------------------------------
2. ขั้นตอนการเก็บข้อมูลท่าทาง (Data Collection)
--------------------------------------------------------------------------------
คุณสามารถเลือกเก็บข้อมูลได้ 2 วิธี ตามความสะดวก:

--------------------------------------------------
วิธีที่ 2A: บันทึกสดผ่านกล้องเว็บแคม (src/collect_data.py หรือใน Tab 2 ของ GUI)
--------------------------------------------------
  2A.1 รันด้วยท่าเริ่มต้น (Default: sawasdee และ khopkhun):
    python src/collect_data.py

  2A.2 กำหนดท่าทางที่ต้องการเก็บเองกี่ท่าก็ได้ ด้วย --words:
    python src/collect_data.py --words sawasdee khopkhun chai mai_chai kho_thot

  พารามิเตอร์ที่สามารถปรับได้:
  --words    : รายชื่อท่าทางที่ต้องการเก็บ (คั่นด้วยช่องว่าง)
  --person   : รหัสผู้ทำท่า เช่น p1, p2 (ค่าเริ่มต้น: p1)
  --duration : ระยะเวลาบันทึกต่อ 1 ครั้ง หน่วยเป็นวินาที (ค่าเริ่มต้น: 1.8)

  ปุ่มควบคุมในหน้าต่างเก็บข้อมูล:
  - กด [1] - [9]      : สลับไปยังท่าทางที่ 1 ถึง 9 ตามลำดับ
  - กด [TAB] หรือ [N] : สลับไปยังท่าถัดไปวนลูป
  - กด [SPACEBAR]     : เริ่มนับถอยหลัง 3.. 2.. 1.. แล้วระบบจะบันทึกท่าทาง (REC สีแดง)
  - กด [D]            : ลบตัวอย่างล่าสุดที่เพิ่งบันทึก (กรณีขยับผิดจังหวะ)
  - กด [Q] / [ESC]    : ปิดโปรแกรมเมื่อเก็บข้อมูลครบถ้วน

--------------------------------------------------
วิธีที่ 2B: สกัดข้อมูลจากคลิปวิดีโอ (src/process_videos.py)
--------------------------------------------------
  เหมาะสำหรับกรณีถ่ายวิดีโอด้วยมือถือหรือกล้องภายนอกไว้ล่วงหน้า:
  
  ขั้นตอน:
  1. ถ่ายคลิปความยาวสั้นๆ ประมาณ 1.5 - 2.0 วินาทีต่อครั้ง (เริ่มยกมือ -> ทำท่า -> จบท่า)
  2. นำไฟล์วิดีโอ (.mp4, .mov, .avi) ไปวางในโฟลเดอร์ videos/<ชื่อท่า>/ เช่น:
       videos/sawasdee/clip_01.mp4
       videos/sawasdee/clip_02.mp4
       videos/khopkhun/clip_01.mp4
  3. รันคำสั่งสกัดพิกัดลง data/raw/ อัตโนมัติ:
       python src/process_videos.py

  ตัวเลือกเสริมสำหรับการสกัดวิดีโอ:
  - ดูภาพโครงร่างกระดูกสดขณะสกัด : python src/process_videos.py --preview
  - วิดีโอถ่ายด้วยกล้องหลัง (ไม่ Flip): python src/process_videos.py --no-flip
  - แปลงเฉพาะไฟล์เดี่ยว          : python src/process_videos.py --video path/to/clip.mp4 --word sawasdee

--------------------------------------------------
คำแนะนำในการเก็บตัวอย่าง:
- แนะนำให้เก็บท่าละประมาณ 20 - 30 ครั้ง (ความเร็วปกติ ช้า และเร็วสลับกัน)
- ท่าสวัสดี/ไหว้: ให้เว้นช่องว่างระหว่างฝ่ามือเล็กน้อย (1-2 ซม.) เพื่อให้เห็นทั้ง 2 มือชัดเจน
- การลบข้อมูลเก่าทั้งหมด: Remove-Item -Recurse -Force data\raw\*


--------------------------------------------------------------------------------
3. ขั้นตอนการเทรนโมเดล (Model Training)
--------------------------------------------------------------------------------
เมื่อเก็บข้อมูลท่าทางครบตามที่ต้องการแล้ว (ระบบจะอ่านทุกท่าใน data/raw/ อัตโนมัติ) ให้รันคำสั่งเทรน:

  วิธีที่ 3.1: เทรนโมเดล Random Forest (Baseline - เสถียรสูง เทรนเร็วมากใน 1-2 วินาที)
  คำสั่ง:
    python src/train_sklearn.py
  ผลลัพธ์:
  - โมเดลจะถูกบันทึกไว้ที่: models/rf.pkl
  - ตารางจับคู่ชื่อท่า: models/labels.json

  วิธีที่ 3.2: เทรนโมเดล PyTorch GRU (เก่งเรื่องลำดับการเคลื่อนไหวตามเวลา)
  คำสั่ง:
    python src/train_torch.py
  ผลลัพธ์:
  - โมเดลจะถูกบันทึกไว้ที่: models/gru.pt
  - ตารางจับคู่ชื่อท่า: models/labels.json


--------------------------------------------------------------------------------
4. ขั้นตอนการทดสอบสดผ่านกล้อง (Real-time Testing)
--------------------------------------------------------------------------------
รันระบบแปลผลสดผ่านกล้อง โดยระบบมีเส้น Ready Zone (ระดับอก) และ State Machine ช่วยควบคุมจังหวะ:

  คำสั่งรันแบบอัตโนมัติ (ตรวจจับการยกมือขึ้นสู่ระดับอกอัตโนมัติ):
    python src/realtime.py

  หรือระบุโมเดลและโหมดที่ต้องการ:
  - ใช้โมเดล Random Forest : python src/realtime.py --model rf
  - ใช้โมเดล PyTorch GRU   : python src/realtime.py --model gru
  - ใช้โหมดกดปุ่ม Spacebar  : python src/realtime.py --mode manual
  - ปรับเกณฑ์ความมั่นใจ 75%: python src/realtime.py --threshold 0.75
  - ปรับระยะเวลาทำท่า 2 วิ : python src/realtime.py --duration 2.0

  ขั้นตอนการทำงานบนหน้าจอ (State Machine):
  1. IDLE (รอ): มีเส้นประ "READY LINE (Chest)" ระดับอก เมื่อมืออยู่ต่ำกว่าเส้น ระบบจะไม่แปล
  2. ARMING (พร้อม): เมื่อยกมือขึ้นเหนือเส้นระดับอกค้างไว้ 0.35 วิ เส้นจะเปลี่ยนเป็นสีเหลือง
  3. RECORDING (กำลังทำท่า): กรอบหน้าจอขึ้นสีแดง REC มีแถบเวลานับ 1.8 วิ ให้ทำท่าทาง
  4. RESULT (แปลผล): บีบอัดข้อมูลเป็น 24 เฟรม แปลผล 1 ครั้ง และแสดงผลค้างไว้ 2.2 วินาที

  ปุ่มควบคุมในหน้าจอ Real-time:
  - [SPACE]        : บังคับเริ่มบันทึกและแปลผลทันที (Trigger Now)
  - [M]            : สลับโหมดอัตโนมัติ (Auto / ยกมือ) กับโหมดกดเอง (Manual / Spacebar)
  - [Q] หรือ [ESC] : ปิดโปรแกรม

6. การแก้ปัญหาเบื้องต้น (Troubleshooting)
--------------------------------------------------------------------------------
1. กล้องเปิดไม่ติด (Cannot open camera):
   - เปิดไฟล์ config.py แล้วแก้ไข CAMERA_INDEX = 0 เป็น 1 หรือ 2 (กรณีมีกล้องหลายตัว)
2. ต้องการล้างข้อมูลเก่าเพื่อเริ่มเก็บใหม่ทั้งหมด:
   - รันคำสั่ง: Remove-Item -Recurse -Force data\raw\*
3. โมเดลทายสลับท่าหรือความมั่นใจต่ำ:
   - ตรวจสอบว่าเก็บข้อมูลแต่ละท่ามีความชัดเจนของทิศทางการเคลื่อนไหวต่างกันจริง
   - แนะนำเก็บเพิ่มเป็น 20 - 30 ตัวอย่างต่อท่า (หลากหลายความเร็ว) เพื่อให้โมเดลเสถียรยิ่งขึ้น
4. ท่าที่มือประกบกัน (เช่น สวัสดี/ไหว้) ตรวจจับยาก:
   - ปรับมุมกล้องให้สูงระดับหน้าผาก แล้วก้มลง 20° - 30° ส่องมาที่ตัว
   - ตอนพนมมือ ให้เว้นช่องว่างระหว่างฝ่ามือประมาณ 1 - 2 ซม. ไม่ประกบแนบสนิท 100%
5. วิดีโอที่ถ่ายด้วยกล้องหลังสกัดออกมาแล้วมือซ้าย-ขวากลับด้าน:
   - เพิ่มตัวเลือก --no-flip ตอนรันสคริปต์: python src/process_videos.py --no-flip

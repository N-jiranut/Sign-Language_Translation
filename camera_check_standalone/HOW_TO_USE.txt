================================================================================
  คู่มือการใช้งาน Standalone Camera Check (เครื่องมือจัดตำแหน่งกล้อง)
================================================================================

เครื่องมือนี้ใช้สำหรับเปิดบน "เครื่องคอมพิวเตอร์ที่ใช้อัดวิดีโอ" 
เพื่อตรวจเช็กว่ามุมกล้อง ระยะห่าง สรีระ และแสงสว่าง ได้มาตรฐานก่อนเริ่มถ่ายทำจริง

--------------------------------------------------------------------------------
1. สิ่งที่ต้องมี และต้องดาวน์โหลดอะไรบ้าง?
--------------------------------------------------------------------------------
สิ่งที่เครื่องต้องมี:
  1. Python (แนะนำเวอร์ชัน 3.10, 3.11 หรือ 3.12)
     - ดาวน์โหลดฟรีจาก: https://www.python.org/downloads/
     - ตอนติดตั้งอย่าลืมติ๊กถูก "Add python.exe to PATH"

สิ่งที่ต้องดาวน์โหลด/ติดตั้งเพิ่ม:
  - โมเดล AI: มีไฟล์ hand_landmarker.task และ pose_landmarker_lite.task 
    ใส่ไว้ในโฟลเดอร์ models/ ให้เรียบร้อยแล้ว ใช้งานแบบ Offline ได้ทันที ไม่ต้องต่อเน็ต
  - ไลบรารี Python: มีเพียง 3 ตัวเบาๆ ใน requirements.txt (mediapipe, opencv-python, numpy)

--------------------------------------------------------------------------------
2. วิธีเปิดใช้งานผ่าน CMD / Terminal (แนะนำที่สุด)
--------------------------------------------------------------------------------
[กรณีที่ 1] รันบนเครื่องอัดวิดีโอภายนอก (เครื่องใหม่ที่ก๊อปปี้โฟลเดอร์นี้ไป):
  
  ขั้นตอนที่ 1: เปิด Command Prompt (CMD) หรือ PowerShell
    - เปิดโฟลเดอร์ camera_check_standalone ใน File Explorer
    - คลิกที่ช่อง Address bar ด้านบน พิมพ์ cmd (หรือ powershell) แล้วกด Enter

  ขั้นตอนที่ 2: สร้างสภาพแวดล้อมเสมือน Virtual Environment (ทำครั้งแรกครั้งเดียว)
    - แนะนำอย่างยิ่งให้สร้าง Virtual Environment (.venv) เพื่อป้องกันไลบรารีตีกับระบบหลัก
    - พิมพ์คำสั่ง:
        python -m venv .venv

  ขั้นตอนที่ 3: เปิดใช้งาน (Activate) Virtual Environment
    - ถ้าใช้ Command Prompt (CMD):
        .venv\Scripts\activate
    - ถ้าใช้ PowerShell:
        .\.venv\Scripts\Activate.ps1
      (หมายเหตุ PowerShell: หากติด Script Execution Policy ให้รันคำสั่งนี้ก่อน:
       Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass แล้วค่อยสั่ง activate อีกครั้ง)
    - เมื่อเปิดใช้งานสำเร็จ จะสังเกตเห็นข้อความ "(.venv)" อยู่หน้าบรรทัดคำสั่ง

  ขั้นตอนที่ 4: พิมพ์คำสั่งติดตั้งไลบรารี (ทำครั้งแรกครั้งเดียว):
        pip install -r requirements.txt

  ขั้นตอนที่ 5: พิมพ์คำสั่งเปิดโปรแกรมตรวจเช็กกล้อง:
        python check_camera.py

  * [เคล็ดลับทางลัด]: เมื่อสร้าง .venv และติดตั้งไลบรารีเสร็จแล้ว ครั้งถัดไปสามารถเปิดโปรแกรม
    ได้ทันทีโดยไม่ต้องสั่ง activate ให้ยุ่งยาก ด้วยการรันผ่าน Path ของ .venv ตรงๆ:
        .\.venv\Scripts\python.exe check_camera.py

  * เมื่อเลิกใช้งาน สามารถปิด Virtual Environment ได้ด้วยคำสั่ง:
        deactivate

[ตัวเลือกเสริมของคำสั่ง]:
  python check_camera.py --camera 1    # สลับกล้อง (กรณีมีเว็บแคมหลายตัว เช่น 0, 1, 2)
  python check_camera.py --no-flip     # ปิดการกลับภาพกระจกเงา (กรณีใช้กล้องหลัง)

3. ค่าการตั้งค่าอุปกรณ์จริงที่ต้องจัด (Calibrated Setup)
--------------------------------------------------------------------------------
  - ความสูงฐานกล้องจากพื้น : 161 ซม.
  - ระยะปลายเท้าถึงกล้อง    : 90 ซม.
  - การจัดมุมกล้อง (Visual Framing - ไม่ต้องใช้เครื่องวัดองศา):
      1. เป้าเล็งวงกลมอยู่กึ่งกลางอก [CENTER OK]
      2. ขอบบนจอ: เหนือศีรษะเล็กน้อย (เว้นที่ว่าง 5 - 10%)
      3. ขอบล่างจอ: อยู่ระดับลิ้นปี่ / ชายโครง / เหนือสะดือ (มือพักบนตักได้สบายๆ)
      4. กางศอก 2 ข้าง: ให้ศอกแตะกรอบซ้าย-ขวาพอดี [ELBOW OK]
      5. มุมก้มกล้อง: ก้มลงจนมองเห็น "หลังมือทั้งสองข้าง" ชัดเจนเวลาทำท่าพนมมือ

--------------------------------------------------------------------------------
4. ในโปรแกรมทำอะไรได้บ้าง? (ฟังก์ชันบนหน้าจอ)
--------------------------------------------------------------------------------
เมื่อโปรแกรมเปิดขึ้นมา จะมีระบบ Visual Alignment HUD ช่วยจัดตำแหน่งแบบเรียลไทม์:

  [1] จุดเล็งกึ่งกลางลำตัว (Center Crosshair & Guideline):
      - มีเส้นประกึ่งกลางจอ และเป้าเล็งวงกลมที่ระดับอก
      - หากนั่งตรงกลาง: เป้าจะขึ้นสีเขียว [CENTER OK]
      - หากนั่งเอียง: จะมีลูกศรสีส้มบอกทิศทาง เช่น "<- SHIFT LEFT" หรือ "SHIFT RIGHT ->"

  [2] กรอบวัดระยะด้วยการกางศอก (Elbow Span Target Zones):
      - มีกรอบวงเล็บมุมที่ขอบจอซ้ายและขวา
      - กางข้อศอกออก 2 ข้าง ให้ศอกแตะในกรอบขอบจอ:
          * ถ้าศอกแตะในกรอบพอดี: ขึ้นสีเขียว [ELBOW OK] แปลว่าระยะ 90 ซม. ถูกต้องเป๊ะ
          * ถ้านั่งใกล้เกินไป: ศอกจะหลุดขอบจอ กรอบจะขึ้นสีแดงเตือนให้ถอยหลัง

  [3] เส้นระดับอก Ready Line (Chest Level):
      - มีเส้นประสีฟ้าขวางระดับอก แสดงจุดแบ่งจังหวะทำท่า:
          * พักมือ = วางมือบนตักต่ำกว่าเส้นนี้
          * เริ่มทำท่า = ยกมือขึ้นพ้นเส้นนี้

  [4] ทดสอบท่าพนมมือ/ยกมือ (Wai Clasp Test):
      - ลองประกบมือพนมท่าสวัสดี ระบบจะขึ้นป้ายสีเขียว:
        "[✓ WAI / CLASP TEST DETECTED]" ยืนยันว่ามุมกล้องก้มลงมาเห็นหลังมือทั้ง 2 ชัดเจน

  [5] แถบสรุปความพร้อม 4 จุดด้านบน:
      - [1] Center: OK
      - [2] Distance: OK
      - [3] Elbows: Inside
      - [4] Hands: 2 Found
      เมื่อผ่านครบทุกเกณฑ์ แถบจะขึ้นสีเขียว:
      "★ ALIGNMENT READY! มุมและระยะพร้อมสำหรับอัดวิดีโอ ★"

5. ปุ่มควบคุมบนคีย์บอร์ด (Shortcuts)
--------------------------------------------------------------------------------
  * สำคัญ: ต้องสลับแป้นพิมพ์เป็นภาษาอังกฤษ (EN) ก่อนกดปุ่มลัด

  [F]          : สลับโหมด Flip ภาพ (Mirror กระจกเงา ON / OFF)
                 * วิธียืนยัน: ยกมือขวาขึ้นมา ป้ายต้องขึ้น "Right" ถ้าขึ้น "Left" ให้กด [F]
  [S]          : บันทึกภาพ Snapshot หน้าจอลงโฟลเดอร์ snapshots/ (เก็บไว้ดูเป็นตัวอย่าง)
  [G]          : เปิด / ปิด เส้นไกด์เล็งบนหน้าจอ
  [R]          : รีเซ็ตสถิติและการตรวจจับ
  [Q] หรือ ESC : ปิดโปรแกรม

6. ปัญหาที่พบบ่อยและวิธีแก้ไข (Troubleshooting สำหรับเครื่องใหม่)
--------------------------------------------------------------------------------
[ปัญหาที่ 1]: พิมพ์ python หรือ python3 แล้วขึ้นเตือน:
  "Python was not found; run without arguments to install from the Microsoft Store..."
  
  สาเหตุ: ตอนติดตั้ง Python ลืมติ๊กถูก "Add python.exe to PATH" ทำให้ระบบ Windows
  นำตัวหลอก (App Execution Aliases) มาครอบไว้แทน
  
  วิธีแก้ไข (เลือกอย่างใดอย่างหนึ่ง):
    - วิธี A: ปิด App Execution Aliases (เร็วที่สุด)
        1. กดปุ่ม Start บน Windows พิมพ์ค้นหา "Manage app execution aliases" แล้วกด Enter
        2. เลื่อนหา "App Installer (python.exe)" และ "App Installer (python3.exe)" 
           แล้วกดสลับเป็น "OFF" ทั้ง 2 ตัว
        3. ปิดหน้าต่าง CMD แล้วเปิดใหม่
    - วิธี B: ติดตั้ง Python ซ่อมแซม
        เปิดไฟล์ติดตั้ง Python (python-installer.exe) อีกครั้ง -> เลือก Modify -> 
        กด Next ไปจนถึงหน้า Advanced Options -> ติ๊กถูก "Add Python to environment variables" -> Install

[ปัญหาที่ 2]: PowerShell ขึ้นตัวหนังสือสีแดงเตือนเรื่อง Execution Policy
  (เช่น "...cannot be loaded because running scripts is disabled on this system")
  
  วิธีแก้ไข:
    พิมพ์คำสั่งนี้ใน PowerShell เพื่อปลดล็อกชั่วคราว:
      Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
    จากนั้นสั่ง .\.venv\Scripts\Activate.ps1 ใหม่อีกครั้ง

[ปัญหาที่ 3]: เปิดกล้องไม่ติด หรือภาพมืด
  - ลองสลับ Index กล้องด้วยคำสั่ง:
      python check_camera.py --camera 1 (หรือ 2)
  - ตรวจสอบว่าแอปอื่น (เช่น Zoom, Teams, Line, Camera) เปิดค้างอยู่หรือไม่ หากมีให้ปิดก่อน

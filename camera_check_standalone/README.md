# Standalone Camera & Posture Calibration Tool
## เครื่องมือจัดตำแหน่งกล้องและสรีระผู้ใช้ (สำหรับเครื่องที่ใช้อัดวิดีโอ)

โฟลเดอร์นี้เป็นเครื่องมือแบบแยกเดี่ยว (Standalone) สามารถคัดลอก (Copy) ทั้งโฟลเดอร์ `camera_check_standalone/` ไปวางบนเครื่องคอมพิวเตอร์หรือแล็ปท็อปที่ใช้สำหรับบันทึกวิดีโอได้ทันที

---

### 1. วิธีเปิดใช้งานผ่าน CMD / Terminal (แนะนำที่สุด)

#### [กรณีที่ 1] รันบนเครื่องอัดวิดีโอภายนอก (เครื่องใหม่ที่ก๊อปปี้โฟลเดอร์นี้ไป)
1. เปิด Command Prompt (CMD) หรือ PowerShell ในโฟลเดอร์นี้
2. สร้างสภาพแวดล้อมเสมือน Virtual Environment (ทำครั้งแรกครั้งเดียว):
   ```bash
   python -m venv .venv
   ```
3. เปิดใช้งาน (Activate) Virtual Environment:
   * **Command Prompt (CMD):**
     ```cmd
     .venv\Scripts\activate
     ```
   * **PowerShell:**
     ```powershell
     .\.venv\Scripts\Activate.ps1
     ```
     *(หากติดข้อความเตือน Script Execution Policy ให้สั่ง `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` ก่อน)*
4. ติดตั้งไลบรารีที่จำเป็นลงใน venv (ทำครั้งแรกครั้งเดียว):
   ```bash
   pip install -r requirements.txt
   ```
5. รันโปรแกรมตรวจเช็กกล้อง:
   ```bash
   python check_camera.py
   ```

> [!TIP]
> **เคล็ดลับทางลัด:** เมื่อสร้าง `.venv` และติดตั้งไลบรารีแล้ว ครั้งถัดไปสามารถเปิดใช้งานได้ทันทีโดยไม่ต้องสั่ง activate ด้วยการรันผ่าน Path ของ `.venv` ตรงๆ:
> ```powershell
> .\.venv\Scripts\python.exe check_camera.py
> ```

#### [กรณีที่ 2] รันบนเครื่องพัฒนาหลัก (เครื่องนี้)
เปิด Terminal ที่โฟลเดอร์โปรเจกต์ แล้วรัน:
```powershell
.\.venv\Scripts\python.exe camera_check_standalone\check_camera.py
```

* **ตัวเลือกเสริม:**
  * `python check_camera.py --camera 1` (สลับไปใช้กล้องตัวที่ 2)
  * `python check_camera.py --no-flip` (ไม่กลับด้านภาพแบบกระจกเงา)

### 2. ค่าการตั้งค่าอุปกรณ์จริงที่ต้องจัด (Calibrated Setup)

* **ความสูงฐานกล้องจากพื้น:** `161 ซม.`
* **ระยะปลายเท้าถึงฐานกล้อง:** `90 ซม.`
* **การจัดมุมกล้อง (Visual Framing - ไม่ต้องใช้เครื่องวัดองศา):**
  1. นั่งให้เป้าเล็งวงกลมอยู่กึ่งกลางอก `[CENTER OK]`
  2. ศีรษะไม่ชนขอบบนจอ (เว้นที่ว่าง 5–10%)
  3. กรอบล่างอยู่ระดับลิ้นปี่ / ชายโครง / เหนือสะดือ (มือวางบนตักได้)
  4. กางศอก 2 ข้าง ให้ศอกแตะในกรอบขอบจอพอดี `[ELBOW OK]`
  5. ก้มหน้ากล้องลงมาจนมองเห็น **หลังมือทั้งสองข้าง** ชัดเจนเวลาทำท่าพนมมือ

### 3. ปุ่มควบคุมบนคีย์บอร์ด (Shortcuts)

> [!IMPORTANT]
> **หมายเหตุ:** ต้องสลับแป้นพิมพ์เป็นภาษาอังกฤษ (EN) ก่อนกดปุ่มลัด

* **[F]** : สลับโหมด Flip ภาพ (Mirror ON / OFF) — *ยกมือขวาขึ้นเช็ก ป้ายต้องขึ้นคำว่า "Right"*
* **[S]** : บันทึกภาพ Snapshot หน้าจอลงโฟลเดอร์ `snapshots/`
* **[G]** : เปิด / ปิด เส้นไกด์เล็งบนหน้าจอ
* **[R]** : รีเซ็ตสถิติและการคำนวณ
* **[Q]** หรือ **[ESC]** : ปิดโปรแกรม
